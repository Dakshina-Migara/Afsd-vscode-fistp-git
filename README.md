# Web Development Fundamentals

A comprehensive collection of web development projects and assignments, covering modern frontend technologies and core programming concepts. This repository serves as a learning journey through the AFSD program at ACPT.

## 🚀 Technologies Used
- **HTML5**: Semantic structure and core web elements.
- **CSS3**: Advanced styling, including:
    - **Flexbox & CSS Grid**: Modern layout techniques.
    - **Animations**: CSS-based transitions and keyframes.
    - **Responsive Design**: Media queries and fluid layouts.
- **JavaScript (ES6+)**: Core logic, DOM manipulation, and asynchronous programming.
- **Frameworks & Libraries**: 
    - **Bootstrap**: Rapid UI development.
    - **Tailwind CSS**: Utility-first styling.
- **API Fetching**: Integration with external data sources.

## 📁 Project Structure
- `Animation/`: Practical examples of CSS animations.
- `Assignments/`: Completed coursework and challenges.
- `Boostrap/`: UI components built with the Bootstrap framework.
- `Events(js)/`: JavaScript event handling and interaction.
- `Fetch/`: Asynchronous data fetching examples.
- `Flex/` & `Grid/`: Masterclass in modern CSS layouts.
- `Java Script/`: Core JS modules and logic.
- `Tailwind/`: Modern, utility-first CSS projects.
- `Java Script/`: Core JS concepts and logic.
- `JS Moduler/`: Modular JavaScript implementation.
